# ארט כרמיאל – אפליקציית חנות

אפליקציית חנות (PWA) לארט כרמיאל: קטלוג מלא של כל המוצרים מהאתר art-karmiel.co.il, עגלת קניות ושליחת הזמנה בוואטסאפ.

## מה יש באפליקציה
- **כל המוצרים מהאתר** (282 כרגע) עם תמונות אמיתיות, מחירים, תיאורים וזמינות במלאי
- 8 קטגוריות ראשיות + תת-קטגוריות (אקריליק, צבעי מים, טושי אלכוהול…)
- חיפוש חכם בעברית שסולח על כתיב מלא/חסר (מכחול/מיכחול, אלכוהל/אלכוהול), מיון, סינון "במלאי" וסינון לפי טווח מחיר
- **גלילה אינסופית** ברשימות מוצרים – מוסיפה מוצרים בלי לטעון מחדש את הדף
- חזרה ממוצר לרשימה – חוזרים בדיוק לאותו מקום בגלילה
- כפתור "חזור" בטלפון סוגר את העגלה/התמונה המוגדלת במקום לצאת מהדף
- דף מוצר: גלריית תמונות עם החלקה בין תמונות, מסך מלא והגדלה בהקשה, כמות, מוצרים דומים, שאלה בוואטסאפ, שיתוף, קישור למוצר באתר
- מועדפים (לב) ו"נצפו לאחרונה"
- עגלה: שינוי כמויות, בחירת איסוף עצמי / משלוח, פרטי לקוח שנשמרים לפעם הבאה
- הזמנה נשלחת בוואטסאפ לחנות בהודעה מסודרת (ובמחשב בלי וואטסאפ – אפשר להעתיק את פרטי ההזמנה)
- מוצר שאזל – כפתור "עדכנו אותי כשיחזור"
- **באנר אופליין** כשאין אינטרנט + עבודה מהמטמון
- תאריך עדכון קטלוג מוצג בפוטר
- מצב כהה/בהיר, התקנה כאפליקציה בטלפון, עובד גם בלי אינטרנט

## עדכון מחירים ומוצרים – אוטומטי
בכל פריסה (Deploy) ב-Render הסקריפט `scripts/update-products.mjs` מושך את כל המוצרים העדכניים מהאתר.
כדי לעדכן את הקטלוג אחרי שינוי מחירים באתר: ב-Render ← השירות ← **Manual Deploy** ← **Deploy latest commit**.
אם האתר לא זמין בזמן הפריסה – נשאר הקטלוג הקודם, שום דבר לא נשבר.

## הגדרות ב-Render (Static Site)
- **Build Command:** `node scripts/update-products.mjs`
- **Publish Directory:** `.`

## קבצים
| קובץ | תפקיד |
|---|---|
| `index.html` | האפליקציה עצמה |
| `products.json` | קטלוג המוצרים |
| `scripts/update-products.mjs` | מעדכן את הקטלוג מהאתר |
| `sw.js`, `manifest.webmanifest`, `icon-*.png` | התקנה כאפליקציה ועבודה בלי אינטרנט |
| `render.yaml` | הגדרות Render |

## שינוי מספר הטלפון / וואטסאפ
בתחילת הסקריפט ב-`index.html`, באובייקט `STORE`.
