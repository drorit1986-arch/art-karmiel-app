# ארט כרמיאל - אפליקציית קטלוג והזמנות

אפליקציית web (חד-קובץ, HTML/CSS/JS) עבור art-karmiel.co.il.

## מה יש כאן
- קטלוג מוצרים לפי קטגוריות
- עגלת קניות
- שליחת הזמנה בוואטסאפ ישירות לחנות (ללא תשלום מקוון)

## מצב נוכחי
הקטלוג מכיל כרגע נתוני דוגמה חלקיים. יוחלף בנתונים אמיתיים (כולל תמונות) דרך WooCommerce REST API.

## פריסה
